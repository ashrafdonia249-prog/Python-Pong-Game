🎮 Python Pong Game

A classic Pong game built with Python and Turtle Graphics, developed as one of my first Python projects.

The project evolved from a basic two-player Pong game into a more complete version with improved UI, game logic, real-time controls, and a computer-controlled opponent.

✨ Features

* 🎮 Player-controlled paddle using keyboard input
* 🤖 Automated computer opponent
* ⚡ Dynamic ball speed
* 🏆 Score tracking and winning score
* ⏸️ Pause and resume
* 🔄 Restart functionality
* 💥 Paddle and wall collision detection
* 🖥️ Custom game-over screen
* 🎨 Custom UI and game design

🛠️ Technologies & Concepts

* Python
* Turtle Graphics
* Keyboard Event Handling
* Functions & Modular Programming
* Conditional Logic
* Real-Time Game Loop
* Collision Detection
* Basic Automated Behavior

🎮 Controls

Key	Action
W	Move paddle up
S	Move paddle down
P	Pause / Resume
R	Restart

The second paddle is controlled automatically by the computer.

📈 Project Development

1️⃣ Basic Pong

Started with the core game mechanics:

* Game window
* Two paddles
* Ball movement
* Keyboard controls
* Wall collision

2️⃣ UI & Game Logic

The game was gradually improved by adding:

* Real-time score tracking
* Winning score
* Paddle collision detection
* Increasing ball speed after paddle collisions
* Pause and restart functionality
* Custom game-over screen
* Improved visual UI

3️⃣ Player vs Computer

The second player was replaced with an automated computer-controlled paddle.

The computer continuously tracks the ball’s Y-coordinate and moves its paddle accordingly.

▶️ How to Run

Clone the repository:

Navigate to the project folder:

Run the game:
